Documentation

Last updated: November 27, 2026

Afterdone watches for Jira work that reaches Done and tells you which Confluence sentences no longer match it. This guide covers setup and daily use.

Requirements

  • Jira Cloud and Confluence Cloud on the same Atlassian site.
  • A Jira administrator to install the App and open the Drift Report.

Install

  1. Install Afterdone from the Atlassian Marketplace and approve the permissions. See the Security page for why each permission is needed.
  2. Make sure the App can see the Confluence spaces you want checked. The App only reads pages it has access to.
  3. That's it. There's nothing to configure to start.

How checks start

  • Issue or Epic moves to Done. This is the main trigger. Any status in Jira's Done category counts. For an Epic, the check also includes its Done child issues.
  • Version released. If your team uses Jira versions, a release checks its Done issues.
  • Manual check. In the Drift Report, enter an issue key such as PROJ-123 and run a check.

Which pages are checked

  • Confluence pages linked to the issue.
  • Pages that mention the issue key in their text.

Up to 5 pages per issue. Tip: link the spec, runbook, or guide to the Epic, or mention the Epic key on the page, so Afterdone knows where to look.

Read the Drift Report

Open Jira, then Settings > Apps > Afterdone - Drift Report. Each finding shows:

  • the page and the issue;
  • the exact sentence on the page that conflicts;
  • what Jira says instead, and why it's a conflict;
  • severity: high (people would act wrongly), medium (misleading), or low (minor or outdated wording).

Fix the page in Confluence, or Dismiss the finding if it's not a real problem. A page that hasn't changed since its last check isn't checked again, so dismissed findings stay quiet.

Email notifications

When a check finds new conflicts, Jira emails the issue's reporter and assignee with the conflicting sentences and a link to the page. Manual checks don't send emails. Jira's own notification settings apply.

Limits

  • Up to 300 checks per site per month. One check compares one issue with one page. Usage is shown in the Drift Report.
  • Very long pages are truncated to their first part for the check.
  • Findings are kept for 180 days.

Good to know

  • Afterdone uses an AI model to compare text. It can miss a conflict or flag a sentence that's fine. Treat findings as suggestions to review.
  • Afterdone never edits your pages or issues.
  • Uninstalling the App removes its data from your site.
